# ZeroPlay Frontend

React + Vite frontend for the ZeroPlay portfolio app.

This package contains the public-facing SPA: routed pages, reusable UI components, auth context, protected-route behavior, and generated soccer data used by the interface.

See the root `README.md` for the full project overview, setup flow, architecture notes, and security posture.

Only `VITE_*` variables are exposed to browser code. Keep backend credentials in `backend/server/.env`.
